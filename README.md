# 📡 Аналітичний Дашборд Тестування Автономності БС — Черкаська ОДА

**Управління цифрового розвитку, цифрових трансформацій та цифровізації Черкаської обласної державної адміністрації**

Даний репозиторій містить інтерактивний аналітичний дашборд результатів тестування автономного живлення базових станцій мобільних мереж (Київстар, Водафон, lifecell) під час блекауту у Черкаській області.

## 📊 Основні можливості дашборду:
- **5 чітких категорій результатів**:
  - 🟢 Успішно пройшли тестування (151 БС)
  - 🔴 Пройшли тестування з перешкодами (127 БС)
  - 🟠 Переплутали сценарій тестування (14 БС)
  - 🔷 Взагалі не заповнили чек-лист (24 БС)
  - ⚪ Не бере участь у тестуванні (132 БС)
- **Інтерактивна фільтрація та дрилл-даун**: швидкий доступ до деталей БС (`Site ID`), населеного пункту, конкретного опису перешкод та контактів відповідальних від ТГ та РВА.
- **Експорт даних у CSV**.
